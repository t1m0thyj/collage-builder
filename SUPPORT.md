# Support

For questions and bug reports, [open a GitHub issue](https://github.com/t1m0thyj/collage-builder/issues). Search existing issues first.

Include:

- what you expected and what happened;
- steps that reproduce the problem;
- browser name and version, operating system, and app version;
- relevant console messages; and
- whether the problem also occurs in a new project.

Do not upload private photos or project files. If a sample is essential, create a minimal project with non-sensitive images.

Security vulnerabilities should not be filed publicly. Follow the [security policy](SECURITY.md) instead.
