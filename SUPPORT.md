# Help and feedback

Need a hand, found a bug, or have an idea? [Open a GitHub issue](https://github.com/t1m0thyj/collage-builder/issues). It's helpful to check existing issues first in case someone has already reported the same thing.

For help getting started, try the [user guide](docs/USER_GUIDE.md) or [offline guide](docs/OFFLINE.md).

## Report a problem

Tell us what you were trying to do, what you expected, and what happened instead. If you can, include:

- The steps that led to the problem.
- Your browser name and version, and your operating system.
- Whether it also happens in a new collage.
- The exact error message or a screenshot.
- The app version and any browser-console errors, if available.

You don't need every detail to report a problem. Start with what you know.

GitHub issues are public, so use sample photos rather than private ones. If a project is needed to show the problem, make a small example with photos you're comfortable sharing.

For a security concern, please use the private reporting process in the [security policy](SECURITY.md).
