# Privacy

Collage Builder is a local-first static web app. It has no account system, analytics, advertising, or application backend. The app does not upload imported images, project contents, exports, or recovery saves.

The following data stays in the browser for the site where the app is hosted:

- imported image data needed by the open project;
- up to five recent recovery saves in IndexedDB;
- preferences and storage-management state; and
- cached application files used for offline loading.

Files leave the app only when you choose to save or export them. Linked projects may ask the browser for permission to read files you selected. Browser permission behavior varies by browser.

The static hosting provider may still receive ordinary request information such as an IP address, user agent, requested URL, and timestamp under that provider's policies. A self-hosted deployment is governed by its operator's policies.

To remove local data, use the recovery-management controls and clear this site's browser data. Clearing site data also removes offline files and may make unsaved projects unrecoverable.

When reporting a problem, do not attach a project or personal photo unless you have removed sensitive content and intend to share it.
